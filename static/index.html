What does each option change?

Writing the book

Subject
Gives the architect the topic to argue and organize around; enter a subject, not a finished title.
Reader
Sets assumed background knowledge, explanation depth, and useful examples. General readers get more foundations; practitioners get applied detail; students get concepts explained; executives get decision-focused framing; specialists get deeper technical language.
Voice
Sets the prose tone—such as plain, narrative, rigorous, or playful—and influences both the outline and chapters.
Length
Sets chapter count and target words per chapter. Longer books request more model output and take longer; Custom lets you choose both values.
Facts, notes and sources
Supplies grounding material for planning and every chapter. The model is asked to use it rather than invent specifics, but it is not a fact-checker.
Voice sample
Guides cadence and diction only. The sample's wording and facts are not meant to be reused.
Point of view
Chooses the narrative perspective (I, we, you, third person, or automatic); conflicting style rules are switched off.
Editorial profile
Applies a bundle of style switches, editing intensity, and house-style instructions. You can adjust each one afterwards; the available profiles are:
Style switches
Tell the writer what to avoid and enable matching checks in the editorial pass. Each switch's description names the pattern it targets.
Editorial de-AI pass
When on, scans finished chapters and selectively rewrites flagged passages. This can change prose, and adds model calls and time.
Intensity
Controls when the editor runs: Gentle at 5+ flags, Standard at 2+, or Aggressive for any flag. Higher intensity can edit more passages.
Banned words and phrases
Lists terms the writer is told to avoid; the editor also checks for them in the draft.
House style
Adds your own short instructions to every chapter prompt—for example, spelling, paragraph length, or naming preferences.
Review the outline
Pauses after planning so you can edit the title, chapters, purposes, and beats before drafting. Turn it off to start writing automatically.
API key / mode
A Groq key enables live model output. Without a key, demo mode uses fixed sample prose and does not generate custom content.

Export layout

File format
Markdown is easy to edit, HTML is for browsers and printing, EPUB is for e-readers, and PDF preserves a fixed page layout.
Page size and margins
Set the page dimensions and printable area; they change layout and page count, not the prose.
Chapter heading
Chooses whether exports label chapters as “Chapter 1”, “1.”, or with the title only.
Body size and line spacing
Change the type size and vertical breathing room, affecting readability and pagination.
Paragraphs and alignment
Choose first-line indents or paragraph gaps, then left alignment or justified text.
New page per chapter
Starts each chapter on a fresh page in PDF and print-ready HTML.
PDF running matter
Adds running headers and page numbers to PDF exports; it does not affect EPUB or Markdown.

Export settings affect presentation only. Page pagination is controlled by the reader in EPUB; Markdown uses the chapter-heading choice.

      A book in one sentence

      Give it a subject.
      Watch a book assemble itself.

      Bookwright stages the work the way an author does: one model designs the argument, another writes each chapter against a running bible of what came before, and a third keeps the book from contradicting itself. Then it typesets.

      • 01 Architect — parts, chapters, beats
      • 02 Writer — chapters, streamed as they land
      • 03 Editor — summaries + glossary for continuity
      • 04 Composer — Markdown, HTML, EPUB, PDF
